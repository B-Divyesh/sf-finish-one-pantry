# Demo sandbox

Open [the demo](/demo/) or add ?demo=1 to the home URL. It starts immediately
with Oat milk, Basmati rice, Laundry detergent, and Coffee beans. Laundry
detergent is already on the shopping list so the result is useful before any
setup.

The demo uses the IndexedDB database named demo:finish-one-pantry. The normal
pantry uses finish-one-pantry, so the two stores never read or write each
other. The persistent banner says “Demo — sample data, nothing is saved.”

Use **Reset demo** to restore the four sample packages. Use **Start for real**
to clear only the demo database and return to the normal pantry. The sample and
its changes are never copied into real data.
